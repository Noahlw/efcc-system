## Acceptance criteria

- [ ] Only an eligible Staff target receives delegation through an independent Admin-authorized Save; crafted Member/protected requests fail.
- [ ] Member→Staff then delegation requires two deliberate successful commands and fresh intermediate state.
- [ ] Staff exit removes delegation; later Staff regrant does not restore it; required effects remain atomic and authoritative.
- [ ] Phone grouping matches desktop relationship while Save/state remain separate; proof, Reset, Keep/Discard and UNKNOWN reuse established behavior.

## Implementation method

3. Retain server SQL-time Staff eligibility, Admin authority, exact withdrawal witness, Staff-exit cleanup and no automatic delegation resurrection on later Staff regrant. Refresh state on confirmed result, preserve same-task choices on known no-write and protect original operation under UNKNOWN. Reuse Security confirmation, disposal and unsaved-departure semantics.
